## How to Add Screenshots:

1. **Run the application:**
   ```bash
   # Use the startup script
   ./start_secure_pass.bat  # Windows
   ./start_secure_pass.sh   # Linux/Mac
   ```

2. **Take screenshots of different pages and features**

3. **Save them in this directory with descriptive names**

4. **Update the main README.md to reference these screenshots**

## Screenshot Guidelines:

- Use consistent window sizes for desktop shots (1280x720 or larger)
- For mobile screenshots, use responsive view in browser dev tools (375x812)
- Include browser chrome to show it's a web application
- Use actual data when possible (not just placeholder text)
- Show different user roles and their respective dashboards
